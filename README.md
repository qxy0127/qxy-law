## 線上預約按鈕怎麼開啟

網站底部 `<script>` 區塊裡有一行：

```js
var BOOKING_URL = "";
```

- **保持空白** → 預約按鈕自動隱藏，訪客只看到電話與 LINE
- **填上預約系統網址** → 預約按鈕自動出現

填法：

```js
var BOOKING_URL = "https://你的預約系統網址/card/booking";
```

只接受 `https://` 或 `http://` 開頭的正式網址；`localhost` 會被自動忽略（本機測試網址訪客連不到）。
